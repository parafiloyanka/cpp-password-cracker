# C++ Password Cracker (SHA-256) 🔐

Консольна утиліта мовою C++ для дослідження стійкості парольного захисту. Програма дозволяє генерувати SHA-256 хеші та тестувати їх на стійкість за допомогою методів Brute-force та словникових атак (Dictionary attack).

## ⚙️ Основний функціонал
- **Генерація хешів:** Створення SHA-256 хешу з відкритого пароля та його збереження у текстовий файл.
- **Brute-Force атака:** Повний перебір комбінацій із можливістю гнучкого налаштування:
  - Вибір наборів символів (малі/великі літери, цифри, спецсимволи).
  - Встановлення максимальної довжини пароля для перебору.
- **Словникова атака (Dictionary Attack):** Перевірка хешу за допомогою заздалегідь підготовленого текстового файлу (словника) з популярними паролями.
- **Бенчмаркінг:** Автоматичний підрахунок часу, витраченого на злом пароля (у секундах).
